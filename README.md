# 📈 Retail Demand Forecasting

Projeto de Ciência de Dados para previsão de demanda utilizando o dataset **M5 Forecasting – Accuracy**, disponibilizado pela Walmart.

O objetivo é desenvolver um pipeline completo de previsão de vendas, seguindo a metodologia **CRISP-DM**, desde o entendimento do problema até a construção e avaliação de modelos de Machine Learning.

---

## Objetivos

- Compreender o problema de negócio.
- Explorar e analisar os dados.
- Desenvolver atributos relevantes para previsão.
- Construir modelos de Machine Learning.
- Avaliar o desempenho dos modelos.
- Documentar todo o processo.

Este projeto utiliza o dataset **M5 Forecasting – Accuracy**.

Para reproduzir o projeto, faça o download do dataset e coloque os arquivos na pasta:

